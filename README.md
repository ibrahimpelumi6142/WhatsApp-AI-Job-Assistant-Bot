# WhatsApp AI Job Assistant (Public Demo)

A **clean open-source demo** of a WhatsApp-based AI job assistant.  
This repo showcases a modular bot that can:  

- Search jobs via multiple APIs (Remotive + JSearch)  
- Handle WhatsApp messages via Cloud API  
- Demonstrate a simple CV generator (HTML → PDF)  
- Provide basic natural language understanding (NLU) for intents  
- Illustrate a clean, modular Python project structure  

⚠️ **No production code, API keys, or private business logic included.**  
This is safe to share publicly as a portfolio project.

---

## 🚀 Features (Public Demo)

- Job search via demo API wrappers  
- WhatsApp webhook example  
- CV generator template (HTML → PDF)  
- Intent recognition sample  
- Clean folder structure and code organization  
- Easily extensible for real projects
